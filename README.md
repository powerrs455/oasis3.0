# For Sherine 💌

A little cute page, hosted as a static website.

## Put it online with GitHub Pages

1. Go to github.com and create a **new repository** (e.g. `for-sherine`). Set it to **Public**.
2. Click **Add file → Upload files** and drag in everything from this folder (`index.html`, `.nojekyll`, `README.md`). Click **Commit changes**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose branch **main** and folder **/ (root)**, then click **Save**.
5. Wait 1 to 2 minutes. Your link will be:
   `https://YOUR-USERNAME.github.io/for-sherine/`

Send her that link. 💖

## Editing

Open `index.html`. To change her name, edit `var NAME="Sherine";`. The cards live in the `steps` list near the bottom.
